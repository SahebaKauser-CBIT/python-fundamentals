
# Python Syntax, Indentation, and Data Types

## 1. Python Syntax
Python uses simple, readable syntax. Statements are generally written one per line.

## 2. Indentation
Python uses indentation to define code blocks. Four spaces are the standard indentation level.

Example:

```python
age = 18

if age >= 18:
    print("You are an adult.")
```

Incorrect indentation can cause an IndentationError.

## 3. Variables
Variables store data values. Python does not require explicit type declarations.

Example:

```python
name = "Saheba"
age = 21
```

## 4. Basic Data Types
- str: Text, such as "Hello"
- int: Whole numbers, such as 25
- float: Decimal numbers, such as 5.5
- bool: True or False values

The type() function identifies a value's data type.

## 5. Input and Output
The input() function reads user input.
The print() function displays output.
The input() function returns a string, so use int() to convert numeric input to an integer.

## 6. Arithmetic Operators
- + Addition
- - Subtraction
- * Multiplication
- / Division
