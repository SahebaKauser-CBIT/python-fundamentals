
# Python Programming Fundamentals

## Overview
This project introduces Python syntax, variables, data types, indentation, arithmetic operations, and user input/output.

## Project Structure

```text
python-fundamentals/
├── README.md
├── .gitignore
├── src/
│   ├── hello_world.py
│   └── user_input.py
└── docs/
    └── syntax_notes.md
```

## Requirements
- Python 3
- VS Code or another code editor
- A terminal or command prompt

## Setup
Install Python 3 from https://www.python.org/downloads/

Verify the installation:

```bash
python --version
```

On Windows, you can also use:

```powershell
py --version
```

## Run the Scripts

```bash
python src/hello_world.py
python src/user_input.py
```

On Windows, if needed, replace `python` with `py`.

## Concepts Learned
- Declaring and using variables
- Strings, integers, floats, and booleans
- Checking types with type()
- Basic arithmetic operations
- Accepting user input and displaying formatted output
- Python indentation rules
